## HIGH RELEVANCE — Directly affects Klatch

### 1. Claude Code: 7 releases in 8 days (v2.1.83 → v2.1.90)

Massive velocity. Key items for Klatch:

| Version | Date | Highlights |
|---------|------|------------|
| v2.1.90 | Apr 1 | `/powerup` lessons, SSE transport perf (linear time for large frames — was quadratic), `--resume` cache miss fix |
| v2.1.89 | Apr 1 | `"defer"` for PreToolUse hooks, `PermissionDenied` hook, named subagents in `@` typeahead, StructuredOutput cache bug fix (~50% failure rate), **thinking summaries off by default** |
| v2.1.87 | Mar 29 | Cowork Dispatch message delivery fix |
| v2.1.86 | Mar 27 | `X-Claude-Code-Session-Id` header, `.jj`/`.sl` VCS exclusion, `--resume` fix |

| v2.1.83 | Mar 25 | `managed-settings.d/`, transcript search, `CwdChanged`/`FileChanged` hooks, `TaskOutput` deprecated |

**Klatch impact:**
- **SSE performance fix (v2.1.90):** Large streamed frames now handled in linear time. Klatch uses SSE for message streaming — this may improve reliability for long responses.
- **`TaskOutput` deprecated (v2.1.83):** Replaced by `Read` on background task output file. If Klatch's JSONL import touches TaskOutput-style patterns, verify compatibility.
- **Thinking summaries off by default (v2.1.89):** Klatch already uses `thinking: { type: 'adaptive', display: 'omitted' }` — no impact, but good to note the ecosystem is converging on this default.

### 2. Message Batches API: 300K output tokens (March 30)

`max_tokens` cap raised to 300K on Message Batches API for Opus 4.6 and Sonnet 4.6. Requires `output-300k-2026-03-24` beta header.

**Klatch impact:** Not directly relevant now (Klatch doesn't use batches), but valuable for future export/synthesis features (Step 10) where long-form generation might be needed.

### 3. 1M context beta retiring for Sonnet 4.5/4 (April 30 deadline)

The `context-1m-2025-08-07` beta header stops working for Sonnet 4.5 and Sonnet 4 on April 30. Sonnet 4.6 and Opus 4.6 support 1M natively without beta headers.

**Klatch impact:** Low risk — Klatch defaults to Opus 4.6 and supports Sonnet 4.6. Verify Klatch doesn't pass the deprecated beta header for any model. If legacy imported channels reference Sonnet 4.5 model IDs, the Models API fallback should handle gracefully.

### 4. Haiku 3 deprecation — April 19 (18 days away)

**Klatch impact:** Klatch uses `claude-haiku-4-5-20251001`. Verify no codepath falls back to Haiku 3 IDs. The Models API route already filters dated IDs — should be clean, but worth a test.

## Synthesis: What this means for Klatch

**The platform is stabilizing around patterns Klatch already uses.** Thinking summaries off by default, adaptive thinking as standard, Models API as the canonical model discovery mechanism — all align with decisions Klatch has already made. The seven Claude Code releases in eight days show extraordinary velocity, but nothing breaks our architecture.

**Two deadlines require verification:**
1. **April 19:** Haiku 3 retirement. Low risk but verify no fallback paths.
2. **April 30:** 1M context beta header retirement for Sonnet 4.5/4. Verify Klatch doesn't pass this header.
