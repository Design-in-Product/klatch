### 2. Claude Code Mods (Oct 1) — TypeScript Plugin System for Agent Behavior

Anthropic launched Claude Code Mods in v2.1.287 (Oct 1, 2026). Mods are TypeScript event handlers shipped inside plugins that run in Claude Code's process and can:
- Intercept and rewrite tool calls before they execute (or approve/deny them)
- Rewrite prompts before they reach the model
- Add new UI panes (e.g., custom diff pane)
- Replace built-in features entirely
- Strip secrets from tool output before Claude reads it

Three of Anthropic's own built-in features were converted to mods at launch: **the diff pane, the agents.md loader, and telemetry** — signaling the system is load-bearing, not experimental. A built-in mod called "You should know" watches for things Claude or the user might miss.

**Security note:** Mods inherit Claude Code's full machine access. No sandbox. This is explicit in the announcement.

**Source:** https://postcutoff.com/e/2026-10-01-claude-code-mods/ | https://aiweekly.co/alerts/anthropic-launches-claude-code-mods-typescript-agent-hooks
**Klatch impact:** Two distinct notes:
(a) **Import fidelity**: The agents.md loader is now a mod — Klatch's Claude Code import path captures CLAUDE.md context at import time. If users have the agents.md mod active with custom behavior, that behavior will not transfer via import. This is a new fidelity gap in Layer 2/3 context transfer.
(b) **Strategic**: Mods define a platform where TypeScript agents can intercept and reshape Claude Code behavior. This is directly adjacent to Klatch's roadmap "permission controls and agent freedom" vision item (ROADMAP.md). Klatch could expose mod-authoring or mod-preview as a feature in the Step 10 export flow.
