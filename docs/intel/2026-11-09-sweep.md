### 2. Message Threads API Beta — LIVE as of November 2, 2026

Anthropic launched Message Threads as a public beta for the Messages API on November 2, 2026. After an initial full-conversation request, a client sends only new turns plus the ID of the previous response — the full history is not resent. Anthropic reports ~35% lower time-to-first-token for long agent loops. Beta header: `message-threads-2026-08-12`. Threads are kept server-side for 5 minutes. SDK 1.1.0 (Oct 21) added the SDK thread helper that sets the header automatically. Available across all Claude models on the Claude API, AWS, Google Cloud, and Microsoft Foundry. Not eligible for ZDR or HIPAA configurations.

**Source:** https://www.unite.ai/anthropic-launches-message-threads-beta-for-long-running-agents | https://platform.claude.com/docs/en/build-with-claude/message-threads
**Klatch impact:** MEDIUM. Klatch's multi-agent roundtable and directed modes build long conversation histories. Message Threads could reduce per-turn payload size for high-entity channels, but Klatch's architecture (SSE streaming over POST) already avoids client-side retransmission. Argus: evaluate whether server-side thread state conflicts or complements Klatch's own SQLite history model — worth a design note rather than immediate code action.
**Prior mentions:** Message threads tracked as pre-release in docs/intel/ from 2026-08-10 through 2026-08-31 and noted in Oct 26 curated sweep (SDK 1.1.0 adds helper). **Delta: feature is now LIVE, not pre-release.**
