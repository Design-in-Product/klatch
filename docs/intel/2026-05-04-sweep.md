## MEDIUM RELEVANCE

### 3. Claude Code 2.1.126 (May 1) — MCP auto-retry and project purge

Claude Code 2.1.126 ships two items relevant to Klatch:

- **MCP server auto-retry**: MCP servers that hit a transient error during startup now auto-retry up to 3 times instead of staying disconnected. This is a client-side behavior change in Claude Code's MCP client. Klatch operates as an MCP server (not a client that spawns MCP subprocesses), so this doesn't change Klatch's code — but it's useful design context: the ecosystem is hardening around transient startup failures.
- **`claude project purge [path]`**: New CLI command to delete all Claude Code state for a project (transcripts, tasks, file history, config entry). Informational — relevant to how users might clean up sessions before importing into Klatch.
- **OpenTelemetry additions**: `stop_reason`, `gen_ai.response.finish_reasons`, and `user_system_prompt` added to LLM request spans. Relevant if Klatch adds observability in a future step.

**Source:** https://releasebot.io/updates/anthropic/claude-code
**Klatch impact:** No immediate action. Note for Phase 5d design: auto-retry pattern is now standard in the MCP client ecosystem.

### 4. MemPalace — viral open-source SQLite-backed AI memory system

Released April 5, 2026; now has 47K GitHub stars. MemPalace gives LLMs persistent cross-session memory using a local SQLite + ChromaDB stack. Key design points: stores conversation history verbatim (no summarization), retrieves via semantic search, 170-token startup cost, 96.6% on LongMemEval benchmark, fully offline. The temporal entity-relationship graph (add/query/invalidate/timeline, SQLite-backed) is architecturally close to what Klatch's Step 11 would need for semantic recall.

**Source:** https://github.com/milla-jovovich/mempalace / https://medium.com/@creativeaininja/mempalace-the-viral-ai-memory-system-that-got-22k-stars-in-48-hours-an-honest-look-and-setup-26c234b0a27b
**Klatch impact:** Review MemPalace's SQLite schema and ChromaDB integration as a design reference before writing Step 11 (FTS5 + semantic search). The 170-token startup target is a useful benchmark discipline. The temporal validity-window design for the entity-relationship graph is a concrete pattern worth considering for channel/entity recall.

### 5. Vercel AI SDK 6 — Agent as first-class TypeScript abstraction

Vercel AI SDK 6 ships the `Agent` interface as a first-class abstraction: define once (model + instructions + tools), use across the app. Includes full MCP support, tool execution approval UI, DevTools, and reranking. Over 20M monthly downloads. This is the dominant TypeScript AI SDK in the ecosystem; its design choices (especially MCP integration and the Agent/ToolLoopAgent split) signal how the TypeScript community will structure agent code going forward.

**Source:** https://vercel.com/blog/ai-sdk-6
**Klatch impact:** Competitive context. Klatch uses the Anthropic SDK directly rather than Vercel AI SDK, which remains the right call (avoids an abstraction layer over our own vendor). But the `ToolLoopAgent` pattern and MCP integration design are worth reviewing as Klatch builds toward more agentic step executions. Watch for friction if users try to combine Klatch's MCP server with Vercel AI SDK 6 clients.
