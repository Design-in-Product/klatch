## HIGH RELEVANCE — Directly affects Klatch

### Claude Code Dispatch / Remote Sessions — Widespread Failures
**Source:** GitHub Issues ([#40179](https://github.com/anthropics/claude-code/issues/40179), [#40257](https://github.com/anthropics/claude-code/issues/40257), [#40178](https://github.com/anthropics/claude-code/issues/40178), [#38049](https://github.com/anthropics/claude-code/issues/38049), [#40283](https://github.com/anthropics/claude-code/issues/40283))
**Impact:** Directly relevant — this is the service disruption xian experienced.

Cluster of related failures in Dispatch/remote session infrastructure as of late March:
- **Core symptom:** Dispatch processes messages on the desktop backend, but responses are never delivered to any client. Messages show "Read" but no response appears.
- **Root cause area:** The cloud relay layer (`CCR` / `transport:ccr`) between desktop and connected clients appears broken. `ToolSearch` for `SendUserMessage` returns "No matching deferred tools found."
- **macOS-specific:** Issue [#40283](https://github.com/anthropics/claude-code/issues/40283) reports `com.apple.vm.networking` entitlement missing from the app, keeping `coworkd` permanently in `NOT_CONNECTED` state.
- **Additional issues:** Sessions ignore user model/permission settings (always defaults to Sonnet + standard permissions, [#39889](https://github.com/anthropics/claude-code/issues/39889)); sessions isolated from Projects with no shared context ([#37713](https://github.com/anthropics/claude-code/issues/37713)).
- **No official fix announced.** Issues remain open. Known 10-minute network timeout requires `claude remote-control` restart.

**Action:** Monitor for resolution. This affects our ability to run remote agent sessions and may be relevant to cloud deployment research.

## Synthesis: What this means for Klatch

**The Dispatch disruption is the most immediately impactful finding.** This cluster of bugs in the remote session infrastructure explains the service disruption xian experienced over the past two days. It's not a Klatch-specific issue — it's a platform-wide problem with the cloud relay layer. No fix has been announced, and the issues remain open. For Klatch's own remote/cloud deployment ambitions, this is a cautionary signal: the platform's remote session infrastructure is still fragile.

**The Mythos leak validates our dynamic model discovery architecture.** Round 12's Models API work means Klatch won't need code changes when new model tiers ship — they'll appear automatically. This was good timing.

**The Haiku 3 deprecation (April 19) is a low-risk deadline.** We already default to Haiku 4.5, and the dynamic model discovery should naturally exclude deprecated models. But a quick audit of any hardcoded Haiku 3 references is warranted before April 19.

**Agent SDK changes hint at where the platform is heading.** The 1M context beta, tools allowlists, and streaming API refinements suggest Anthropic is investing heavily in the agent runtime. Klatch's current direct-SDK approach is fine for now, but the Agent SDK may become the preferred integration path for conversation-management tools like ours.
