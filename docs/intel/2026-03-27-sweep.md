## Synthesis: What this means for Klatch

**The multi-agent space is maturing, and Klatch has quiet advantages.** Agent Teams' stability fixes and the community request for per-entity model selection validate decisions Klatch made early: named entities with independent models, persistent history, project-scoped context. These aren't on Agent Teams' roadmap yet. The gap is closing but Klatch's conversation-centric, persistent model remains distinct from the session-scoped, terminal-centric Agent Teams approach.

**MCP Apps is the most interesting new capability since the last sweep.** Rich interactive tool outputs rendered in sandboxed iframes — this could inform how Klatch handles artifacts in Step 9. If an entity's response includes interactive content (a chart, a form, a code sandbox), MCP Apps provides a rendering model. Worth a deeper look once Step 9 stabilizes.

**Structured outputs going GA removes a friction point for Step 10.** When we build export/context packaging, we may want Claude to produce structured manifests (what transferred, what didn't, what the user should do). Structured outputs make that reliable without prompt gymnastics.
