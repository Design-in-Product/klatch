## HIGH RELEVANCE

### 1. Claude Code v2.1.208–2.1.215 Batch — Worktree Bug Fix, /fork Redesign, /verify Change

Multiple releases in the 7-day window. Most operationally significant for Klatch:

**v2.1.210 (July 14) — `isolation: 'worktree'` correctness fix:**
Subagents with `isolation: 'worktree'` were running git-mutating commands against the **main repo checkout** instead of their isolated worktree. This is now fixed. Klatch's agent team (Daedalus, Argus, Iris) all work in persistent duty-cycle worktrees under `.claude/worktrees/` — any worktree-isolated subagent calls they made before this fix may have unintentionally modified main.

**v2.1.212 (July 17) — `/fork` redesigned; `/subtask` added; session loop guards:**
`/fork` now copies the conversation into a new **background session** instead of an in-session subagent. The in-session subagent path is replaced by `/subtask`. WebSearch capped at 200 calls/session; subagent spawns capped at 200 (configurable). `/resume` picker added for selecting past sessions.

**v2.1.215 (July 19) — `/verify` and `/code-review` skills no longer auto-run:**
Must now be invoked explicitly. If either skill was wired into a hook (`PreToolUse` / `PostToolUse`) with auto-invoke intent, that behavior has changed.

**v2.1.214 (July 18) — Permission security fixes:**
`dir/**` allow rules (e.g., `Edit(src/**)`) were incorrectly auto-approving writes to nested dirs anywhere in the tree, not just under `<cwd>/dir`. Fixed. Also: Windows PowerShell 5.1 permission-check bypass fixed; bidirectional-override characters neutralized in permission previews.

**Source:** https://code.claude.com/docs/en/changelog
**Klatch impact:** (a) Worktree bug fix is immediately relevant — confirm agents' pre-7/14 worktree work didn't inadvertently touch main. (b) `/verify` workflow change: Argus's review-gate habit uses `/code-review`; confirm this is still working as expected post-v2.1.215. (c) Permission fix: Klatch's CCR sessions may have had over-broad `Edit(src/**)` grants before — no damage expected since CCR is ephemeral, but worth noting.
**Prior mentions:** Claude Code tracked in multiple sweeps; 2.1.207 in 7/13 sweep. Worktree bug fix and /fork redesign are fresh deltas this window.
**Verified against:** CCR environment runs Claude Code; worktree-isolated subagent calls occur in Daedalus/Argus/Iris duty cycles. Bug confirmed in v2.1.209 era; fixed v2.1.210.

### 2. Bloome — Multi-Agent, Multi-Model Conversation Platform (Launched July 1)

Bloome (bloome.im) launched publicly as a messaging platform where humans and AI agents collaborate in the same conversation thread. Multi-agent by default: one agent drafts, another challenges, a third consolidates. Supports Claude, GPT-4o, Gemini, DeepSeek, and custom agents in the same thread. Targeted at solo operators and small teams.

This is the closest architectural analog to Klatch found in any sweep to date.

**Differentiators Klatch has that Bloome lacks:**
- Local-first / no cloud dependency
- Import of existing Claude agent conversations with context continuity (the active beta gap Klatch is solving)
- Agent persona continuity across sessions (Step 10.5)
- The entity IS its conversation history, not a model selection
- Imported, continuing agent conversations as first-class entities (the Klatch premise)

**Bloome advantages Klatch lacks:** cloud-hosted (no setup), multi-vendor out of box, team collaboration.

**Source:** https://bloome.im; https://www.accessnewswire.com/newsroom/en/industrial-and-manufacturing/bloome-launches-a-messaging-platform-where-humans-and-ai-agents-work-t-1185004
**Klatch impact:** First cloud-hosted multi-agent/multi-model conversation product to appear in these sweeps. The composition continuity gap (currently blocking Klatch's beta) is Klatch's key differentiator from Bloome — agents in Bloome carry only their L5 prompt, exactly as Klatch entities do today. Closing the continuity gap makes Klatch structurally distinct. Route to Calliope for cross-poll brief framing + PREMISE.md context.
**Prior mentions:** Multi-vendor/multi-model topics appear in `docs/intel/2026-04-20-sweep.md`, `2026-06-08-sweep.md`, `2026-06-21-sweep-curated.md`, and `docs/mail/read/argus-to-calliope-sweep13-vendor-risk-2026-06-21.md` — but all in the context of Klatch's own roadmap vision; Bloome as a specific product is a **genuinely new find**.
