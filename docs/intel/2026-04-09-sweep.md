## HIGH RELEVANCE — Directly affects Klatch

### 1. Hono v4.12.12: Five Security Fixes (April 7)

Hono released v4.12.12 on April 7 with five security patches: path normalization bypass
(`//` repeated slashes bypassing route middleware), SSG path traversal via crafted
`ssgParams`, IPv4-mapped IPv6 bypass of IP restriction rules, missing cookie name
validation, and cookie prefix bypass via non-breaking spaces. Klatch is pinned to
`^4.6.0` — over 6 minor versions behind the patched release.

**Source:** https://github.com/honojs/hono/releases
**Klatch impact:** Klatch's server (`packages/server`) uses Hono. None of the five
affected features (serveStatic, SSG, IP restriction) appear to be active in Klatch
today — grep confirms no usage. However, the cookie validation fixes and route
middleware path-normalization patch are structural hardening that applies broadly.
Upgrade to `^4.12.12` is low-risk and closes residual exposure. Argus should verify
and flag to Daedalus for a targeted `npm update hono` pass.

### 2. Claude Managed Agents Launches in Public Beta (April 8)

Anthropic launched Claude Managed Agents — a server-side agent harness with built-in
tool execution, compaction, prompt caching, MCP server support, and persistent SSE
streaming sessions. Requires the `managed-agents-2026-04-01` beta header. SDK support
shipped in `@anthropic-ai/sdk` v0.86.0 (also April 8). Sessions use the same
SSE event pattern Klatch already implements. Multi-agent and memory features are in
research preview (separate access request required). Pricing: $0.08/hour runtime plus
standard token costs.

**Source:** https://siliconangle.com/2026/04/08/anthropic-launches-claude-managed-agents-speed-ai-agent-development/
**Klatch impact:** Directly intersects Step 10 (Export + meta-model synthesis), which
explicitly plans to use "the Claude Agent SDK to seed a new Code session." Managed
Agents is the infrastructure vehicle for that plan. The Agents/Sessions/Environments
model also maps onto Klatch's entity/channel/project model. Argus should read the
docs and brief Daedalus before Step 10 implementation begins. The Klatch-as-MCP-service
vision (Someday/Maybe section) is now a well-specified upstream target.

### 3. Anthropic TypeScript SDK: 8 Versions Behind (Current: v0.86.1)

Klatch pins `@anthropic-ai/sdk: ^0.78.0`. Between April 1–8 alone, five new minor
versions shipped (v0.82–v0.86.1). Key changes in the gap: `structured stop_details`

signals that Anthropic is centralizing compaction inside Managed Agents — Klatch's

to confirm no regressions in the streaming bridge (`packages/server/src/claude/client.ts`).
Daedalus should schedule this bump before Step 10 begins.

### 4. Vite 8.0.7 Now Stable; Rolldown Replaces esbuild/Rollup (Released March 12, patched through April 7)

delivering 10–30x faster builds. `@vitejs/plugin-react` v6 drops Babel as a dependency.
v8.0.7 is the latest stable patch (April 7). Klatch's client uses Vite with no pinned
major version constraint.

**Source:** https://vite.dev/blog/announcing-vite8-beta
**Klatch impact:** Upgrade from Vite 7/8 beta to v8 stable is not urgent — current
Vite configuration works. But the Babel removal in `plugin-react` v6 could break
projects using Babel plugins. Klatch should audit before upgrading. Iris (UX/frontend)
should note this for her upcoming UI work — faster incremental builds would improve
her dev loop.

### 7. Anthropic Cuts Claude Subscription Access in Third-Party Harnesses

Anthropic blocked Claude Pro/Max subscription limits from being used in third-party
agent tools like OpenClaw, effective April 4. Users must now use API keys or a new
pay-as-you-go add-on. Rationale: heavy users were running $1,000–$5,000/day equivalent
through $200/month plans by bypassing Anthropic's caching layer.

**Klatch impact:** None — Klatch uses API keys directly. This is a pricing enforcement
story about subscription abuse, not API behavior.
