### 3. Claude Code 2.1.178–2.1.185 (June 15–20) — Agent Teams Restructuring + Destructive Command Blocking

Model deprecation warnings added.
- **2.1.185 (June 20):** Stream-stall hint text improved; 10s → 20s trigger threshold.

### 4. MCP Enterprise-Managed Authorization (June 18) — Okta-Based Admin Provisioning

Anthropic shipped Enterprise-Managed Authorization (EMA) for MCP connectors on June 18. Admins authorize connectors once via Okta (first supported IdP), scoped by group/role; employees get connectors auto-provisioned on first login. Uses the ID-JAG standard (Identity JWT Authorization Grant, IETF OAuth WG, incorporated into MCP spec November 2025). Addresses governance gaps from per-user OAuth tokens with no centralized expiry control.

**Source:** https://explainx.ai/blog/anthropic-claude-enterprise-managed-auth-mcp-okta-2026 / https://workos.com/blog/everything-your-team-needs-to-know-about-mcp-in-2026
**Klatch impact:** Klatch runs as a **stdio MCP server** — EMA is an enterprise/HTTP MCP server concern. No immediate code change needed for 1.0. Ecosystem signal: the MCP governance surface is expanding; enterprise deployments of Klatch (if ever) would benefit from this pattern. Also relevant to the "Klatch as universal context transport (MCP service)" Someday/Maybe roadmap item.
**Prior mentions:** MCP enterprise auth — `docs/STEP10-RETROSPECTIVE-CALLIOPE.md`, `docs/briefs/cross-pollination/2026-04-10.md`, `docs/intel/2026-06-08-sweep.md` (general MCP enterprise context). EMA as a specific Anthropic feature launch is a fresh find.
