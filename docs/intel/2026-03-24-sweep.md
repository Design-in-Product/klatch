### 1. Claude Computer Use — Research Preview (March 23)

**Relevance: 2 — Strategic signal, no immediate action**

### 2. Automatic Prompt Caching — Now Available (NEW)

**Relevance: 3 — Cost reduction with minimal code change**

Single `cache_control` field on the API request body. The system auto-caches the last cacheable block and advances the cache point. No manual breakpoint management required.

Klatch sends full conversation history on every message. Auto-caching could cut costs significantly with a one-line addition to the API call in `client.ts`. This is the lowest-effort, highest-value optimization available right now.

**Source:** [Anthropic Platform Docs](https://platform.claude.com/docs/en/release-notes/overview)

### 3. Output Token Limits — 64K Default, 128K Upper Bound for Opus 4.6 (NEW)

**Relevance: 3 — Requires audit of hardcoded limits**

Default max output tokens boosted to 64K. Upper bound is now 128K for Opus 4.6. Klatch's `max_tokens` setting in `client.ts` (currently 16K per v0.8.8) should be reviewed. The gap between our 16K setting and the 64K default means we're leaving capability on the table — or intentionally constraining for cost/UX reasons (which is fine, but should be a documented choice).

**Source:** [Laravel News](https://laravel-news.com/claude-opus-4-6)

### 4. 1M Context Window — GA at Standard Pricing (UPDATE)

**Relevance: 2 — Removes cost barrier for long conversations**

The long-context premium has been dropped for Opus 4.6 and Sonnet 4.6. 1M context at standard rates. Previously covered as beta; now GA. Combined with the Compaction API, this means Klatch channels can handle significantly longer conversations without cost penalty.

**Source:** [Anthropic](https://www.anthropic.com/news/claude-opus-4-6)

### 5. Vite 8 + Rolldown Released (NEW)

**Relevance: 3 — Major build tooling upgrade available**

Vite 8 ships with Rolldown (Rust-based bundler): 10-30x faster builds, full plugin compatibility. Most significant architectural change since Vite 2. `@vitejs/plugin-react` v6 drops Babel entirely, uses Oxc for React Refresh. Experimental "Full Bundle Mode" offers 3x faster dev server startup.

Klatch uses Vite + React. This is a direct upgrade path. Not urgent, but when we next touch the build config, this is the target.

**Source:** [Vite Releases](https://vite.dev/releases)

### 6. TypeScript SDK v0.67.0 (March 23) (NEW)

**Relevance: 2 — Should verify Klatch's pinned version**

Latest SDK adds API support for agent skills. v0.66.0 added `context-management-2025-06-27` beta header (needed for Compaction API) and `model-context-window-exceeded-2025-08-26` header. Klatch should check its pinned SDK version — Compaction API adoption requires >= v0.66.0.

**Source:** [GitHub anthropic-sdk-typescript](https://github.com/anthropics/anthropic-sdk-typescript/blob/main/CHANGELOG.md)

### 9. MCP 2026 Roadmap Published (March 9)

**Relevance: 2 — Informs Klatch's "MCP Service" roadmap item**

Four priorities: transport scalability (stateless Streamable HTTP, session migration, MCP Server Cards via `.well-known` URLs), enterprise readiness (auth, observability, gateways), governance maturation, agent communication. The transport evolution toward stateless HTTP aligns with Klatch's SSE architecture. Relevant if Klatch ever exposes channels as MCP resources.

**Source:** [MCP Blog](http://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/)

### 10. OpenClaw — 210K GitHub Stars (NEW)

**Relevance: 3 — Closest open-source competitor**

Open-source personal AI assistant connecting WhatsApp, Telegram, Slack, Discord, Signal, iMessage, Teams. Self-hosted, local-first. This is the most direct competitor to Klatch's vision — multi-channel, local, self-hosted. Their approach to local-first RAG with SQLite (chunks Markdown, generates embeddings, stores in .sqlite for hybrid search) is worth studying.

LibreChat is also worth noting: unified multi-provider conversation interface with MCP support, agents, file handling. Different philosophy (multi-provider vs. Klatch's Anthropic-focused), but overlapping UX.

**Source:** [GitHub OpenClaw](https://github.com/openclaw/openclaw), [LibreChat](https://www.librechat.ai/)

### 11. SQLite Renaissance Continues (TREND)

**Relevance: 2 — Validates Klatch's architecture**

SQLite moving from prototyping to production across the ecosystem: Turso, Cloudflare D1, LibSQL, Litestream. LiveStore (SQLite-based data layer with signal-based reactivity for live query results) is particularly interesting for local-first apps — could inform Klatch's real-time data layer. EU AI Act enforcement driving local-first adoption.

**Source:** [DEV.to SQLite Renaissance](https://dev.to/pockit_tools/the-sqlite-renaissance-why-the-worlds-most-deployed-database-is-taking-over-production-in-2026-3jcc), [LiveStore](https://expo.dev/blog/local-first-application-development-with-livestore)
