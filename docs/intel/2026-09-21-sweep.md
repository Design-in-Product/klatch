## HIGH RELEVANCE

### 1. Messages API On-Demand Compaction Beta (compact-2026-09-04)

Anthropic added server-side on-demand conversation compaction to the Messages API, announced September 14. Send the top-level `compaction` parameter with the `compact-2026-09-04` beta header; the API returns a signed compaction block summarizing the messages you sent. On later requests, send that block first, in place of those messages. The caller controls when to compact; compaction can run in the background; recent turns are kept word-for-word after the summary; prompt cache and thinking validity are preserved in the kept turns.

SDK v0.127.0 (Sep 18) adds `compactBeforeNextTurn()` to the tool runner as a direct bridge to this API (#682 in SDK changelog).

**Source:** https://platform.claude.com/docs/en/build-with-claude/compaction | https://github.com/anthropics/anthropic-sdk-typescript/releases/tag/sdk-v0.127.0
**Klatch impact:** Klatch already implements local compaction (threshold tuned to 160K in Step 9; `fork-continuity.test.ts` covers the path). This API primitive is a new *delegation* option: Klatch could offload the summarization work to Anthropic's server rather than managing it locally. Two architecture questions for Daedalus: (a) does server-side compaction replace Klatch's local approach, supplement it, or compete with it on cost/control? (b) `compactBeforeNextTurn()` is designed for streaming tool-runner loops — relevant to any future entity streaming that wraps the SDK tool runner. Not an emergency; worth an evaluation pass.
**Prior mentions:** "compact" appears widely in intel and mail (Klatch's *local* compaction), but the API-native `compact-2026-09-04` feature is new — no prior hits found. **Frame as: new API primitive, distinct from Klatch's existing local compaction.**
**Verified against:** `packages/server/src/__tests__/fixtures/compaction-subagent.jsonl` and `fork-continuity.test.ts` confirm local compaction path exists; no `compact-2026-09-04` or `compactBeforeNextTurn` found in `packages/` — server-side feature not yet adopted.
