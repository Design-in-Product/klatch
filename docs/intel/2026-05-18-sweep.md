## HIGH RELEVANCE

### 1. Anthropic June 15 billing split — Agent SDK moves to separate credit pool

Announced May 14, 2026. Starting June 15, four surfaces leave the Claude subscription pool and draw from a new "Agent SDK credit" budget billed at full API rates: the Claude Agent SDK (Python + TypeScript), `claude -p` headless mode, official Claude Code GitHub Actions, and any third-party app built on the Agent SDK. Interactive use (Claude Code CLI, claude.ai, Claude Cowork) stays in the subscription. New monthly credit amounts per plan: Pro $20, Max 5x $100, Max 20x $200. Credits do not roll over.

**Source:** https://thenewstack.io/anthropic-agent-sdk-credits/ / https://the-decoder.com/claude-subscriptions-get-separate-budgets-for-programmatic-use-billed-at-full-api-prices/
**Klatch impact:** Klatch uses direct API keys (not subscription-based access), so Klatch's own token budget is unaffected. However: (a) users who currently access Klatch via a subscription-funded path should note this change; (b) the "export to Claude Code" vision (Step 10) includes seeding an Agent SDK session — that export path now draws from the user's Agent SDK credit pool, not their subscription; (c) the $20/$100/$200 monthly ceilings could matter for AAXT automation that runs many probing sessions via the Agent SDK. Worth a sentence in future export UX: "Agent SDK sessions draw from your Agent SDK credit, not your Claude subscription."
**Prior mentions:** `docs/mail/calliope-to-daedalus-default-flip-approved-2026-05-12.md` mentions "billing surprises" as a model-flip judgment criterion — no prior coverage of this specific June 15 structural split.

### 3. MCP 2026 roadmap — stateless HTTP transport, .well-known capability discovery

MCP steering committee published the 2026 roadmap (March, surfacing again in May coverage). Three key features for production-grade deployment: (a) **stateless HTTP transport variant** — adds horizontal-scaling support and stateless session handling for HTTP-based MCP servers; currently in review as an SEP; (b) **`.well-known` capability discovery** — server capabilities discoverable without a live connection via a standardized metadata format; (c) **enterprise readiness** — SSO integration, audit trails, configuration portability (likely as extensions). No specific launch dates; maintainers explicitly note uncertainty.

**Source:** https://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/ / https://thenewstack.io/model-context-protocol-roadmap-2026/
**Klatch impact:** The stateless HTTP transport SEP is the most architecturally significant for Klatch. ### 4. Claude Code 2.1.143 (May 15) — worktree isolation setting, plugin deps

Claude Code 2.1.143 shipped May 15. Key changes: `worktree.bgIsolation: "none"` setting allows background sessions to edit the working copy directly (no EnterWorktree required, for repos where worktrees are impractical); plugin dependency enforcement now refuses `disable` when a dependent plugin is active (with a copy-pasteable disable-chain hint); `claude plugin enable` force-enables transitive dependencies; projected context cost (per-turn and per-invocation token estimates) added to plugin marketplace browse pane.

**Source:** https://releasebot.io/updates/anthropic/claude-code / https://claudefa.st/blog/guide/changelog
