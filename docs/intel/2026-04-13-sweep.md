## HIGH RELEVANCE — Directly affects Klatch

### 1. Claude Haiku 3 (`claude-3-haiku-20240307`) retires April 19–20 — hard deadline in 7 days

Claude Haiku 3 was deprecated February 19, 2026; the retirement date is April 19–20, 2026 (API docs show April 19 in one place, April 20 in the deprecations table — treat as imminent). After retirement, all API calls to `claude-3-haiku-20240307` will return an error. Anthropic's recommended replacement is `claude-haiku-4-5-20251001`.

**Source:** https://platform.claude.com/docs/en/about-claude/model-deprecations

**Klatch impact:**
- `AVAILABLE_MODELS` in `packages/shared/src/types.ts` correctly excludes the deprecated model; dynamic models API won't return it after retirement. No user-facing model selector issue.
- **Potential bug in `MODEL_ALIASES`**: The alias key is `'claude-haiku-3-20250307'` but the actual deprecated model ID is `'claude-3-haiku-20240307'` — the order (`haiku-3` vs `3-haiku`) and year (2025 vs 2024) are both wrong. This alias would fail to resolve channels whose stored model is `claude-3-haiku-20240307`.
- **Risk**: Any Klatch channel with `model = 'claude-3-haiku-20240307'` in the DB — likely from imported claude.ai or Claude Code sessions that used Haiku 3 — will fail to send messages after the retirement date.
- **Action needed**: Daedalus should (a) fix the alias key typo, (b) run a DB query to find channels with this model ID and migrate them to `claude-haiku-4-5-20251001`.

## MEDIUM RELEVANCE — Worth tracking

### 2. Advisor Tool launched April 9 — new orchestration primitive

Anthropic launched the advisor tool in public beta (April 9, 2026), missed by the April 9 automated sweep due to timing. It pairs a fast executor model with a higher-intelligence advisor model that provides strategic guidance mid-generation — close to advisor-solo quality at executor-model rates. Beta header: `advisor-tool-2026-03-01`.

**Source:** https://platform.claude.com/docs/en/release-notes/overview

**Klatch impact:** Orthogonal to Klatch's multi-entity architecture (Klatch runs entities in parallel/sequence with full separate prompts; the advisor tool is a within-stream primitive). However, the executor/advisor split is an interesting alternative to roundtable mode for tasks where one model should supervise another. Worth flagging to Daedalus for Step 10/11 design thinking. No immediate codebase action.

### 3. 1M token context beta retirement for Sonnet 4.5 and Sonnet 4 — April 30

Anthropic announced on March 30 that the `context-1m-2025-08-07` beta header will stop working for Claude Sonnet 4.5 and Claude Sonnet 4 on April 30, 2026. Requests exceeding the standard 200k-token window on those models will return an error. Migration path: Claude Sonnet 4.6 and Opus 4.6 support 1M context at standard pricing with no beta header.

**Source:** https://platform.claude.com/docs/en/release-notes/overview

**Klatch impact:** `AVAILABLE_MODELS` doesn't include Sonnet 4 or Sonnet 4.5 as first-class options, and Klatch's models route skips dated model IDs. However, imported channels may have `claude-sonnet-4-20250514` or `claude-sonnet-4-5-20250929` as stored model IDs. If `MODEL_ALIASES` maps these correctly (it does: `claude-sonnet-4-20250514` → `claude-sonnet-4-6`), those channels will send API calls to the alias. If any were relying on the 1M beta header being passed, that will silently fail. Klatch doesn't appear to send the `context-1m-2025-08-07` header, so the retirement has no effect.
