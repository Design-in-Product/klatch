## HIGH RELEVANCE — Directly affects Klatch

### 1. Claude Code Channels (shipped today, v2.1.80)

Claude Code can now connect to **Discord and Telegram** via MCP servers, enabling two-way messaging with a running session. Start with `--channels` flag. Events flow through MCP; plugins for Telegram and Discord ship pre-built.

**Why it matters for Klatch:** This is architecturally very close to what Klatch does — a messaging interface for AI conversations. Key differences: Channels requires an active terminal session, is session-scoped (not persistent), and routes through existing chat platforms rather than providing its own UI. Klatch's value proposition (persistent history, multi-entity roundtables, project organization, import/export) remains distinct. But Channels validates the core thesis that developers want chat-style interfaces to coding agents. Watch for: whether Channels gains persistence, multi-agent support, or conversation history — those would be convergence signals.

**Source:** [VentureBeat](https://venturebeat.com/orchestration/anthropic-just-shipped-an-openclaw-killer-called-claude-code-channels)

### 2. Cowork Scheduled Tasks (Desktop App)

The Claude Desktop app (Cowork) now supports **persistent scheduled tasks** — define a task, pick a cadence (daily, weekly, hourly, on-demand), and Cowork runs it automatically. Each task spins up its own session with full tool/MCP access. Tasks survive app restarts. Only runs while the app is open.

**Why it matters for Klatch:** This is the mechanism for implementing a standing intelligence feed (see `docs/INTELLIGENCE.md`). A Cowork scheduled task could wake up daily, search for news, and write findings to the Klatch repo. Also relevant as a general automation layer for Klatch development workflows (nightly test runs, pre-session briefings, etc.).

**Source:** [Claude Help Center](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-cowork), [Claude Code Docs](https://code.claude.com/docs/en/scheduled-tasks)

### 3. 1M Token Context Window — GA

1M context is now generally available for Opus 4.6 and Sonnet 4.6 at standard pricing. No beta header required. Media limit raised to 600 images/PDFs per request.

**Why it matters for Klatch:** Imported conversations and long multi-agent sessions can now fit entirely in context. The 5-layer prompt assembly system we built may benefit — less pressure to truncate project memory or kit briefings. Also expands what's possible for whole-project analysis.

**Source:** [Anthropic Platform Docs](https://platform.claude.com/docs/en/release-notes/overview)

### 4. MCP Tool Search (Lazy Loading)

Claude Code now lazy-loads MCP tools instead of preloading all definitions. Token usage drops from ~134k to ~5k when tool descriptions exceed 10% of context. Accuracy improved significantly.

**Why it matters for Klatch:** If we ever expose Klatch entities as MCP tools (a stretch goal), this scaling improvement means the tool ecosystem can grow without context pressure. More immediately, it validates MCP as a viable integration layer at scale.

**Source:** [VentureBeat](https://venturebeat.com/ai/the-open-source-model-context-protocol-was-just-updated-heres-why-its-a-big-deal)

## Synthesis: What this means for Klatch

The biggest takeaway is **convergence**. Anthropic is building toward the same space Klatch occupies — persistent, multi-surface, chat-style interfaces to AI agents. Channels (Discord/Telegram), Remote Control (mobile), and Cowork scheduled tasks all point in this direction.

**Klatch's differentiation remains strong:**
- Persistent, organized conversation history (Channels is session-scoped)
- Multi-entity roundtables (no equivalent in Claude Code)
- Import/export across Claude Code and claude.ai (unique capability)
- Project-level organization with memory and instructions
- Local-first, single-user, no auth overhead

**Strategic watch items:**
1. If Channels gains persistence and conversation history, that's direct competition
2. If Cowork adds multi-agent orchestration, watch for roundtable-like features
3. MCP as integration layer is now industry-standard — building on it is safe
4. 1M context removes constraints we were designing around — revisit truncation logic

- [ ] Verify Haiku 3 isn't offered in entity model selector
- [ ] Consider using Cowork scheduled tasks for this intelligence feed
- [ ] Evaluate whether `--channels` MCP pattern could be used to bridge Klatch ↔ Claude Code sessions
