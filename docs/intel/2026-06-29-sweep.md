Anthropic Workload Identity Federation (WIF) went generally available June 17, 2026. Replaces static `sk-ant-...` API keys with short-lived OIDC tokens from any compliant IdP (AWS IAM, GCP, Azure, GitHub Actions, Okta, Kubernetes SPIFFE). Existing API keys continue to work alongside WIF. Compatible with all Claude API endpoints including the Anthropic SDK and Claude Code.

This falls in the 6/15–6/22 window covered by the 6/22 sweep but was not included there — flagging as a missed item.

**Source:** https://claude.com/blog/workload-identity-federation

Team agents currently authenticate via personal API keys in Claude Code sessions — WIF could replace those in future CI/automation contexts.
