## HIGH RELEVANCE

### 1. Anthropic Managed Agents Memory — `agent-memory-2026-07-22` Beta Header Stable in SDK 0.110.0

Anthropic published the `agent-memory-2026-07-22` beta header, tightening and versioning the Managed Agents memory API: memory listing now returns stable server-defined order; `depth` accepts only 0, 1, or omitted; `path_prefix` must end with `/` and matches whole segments. Replaces `managed-agents-2026-04-01` (sending both returns 400). TypeScript SDK 0.110.0 ships this header by default on all memory store calls. Klatch already pins `^0.110.0` per the July 5 bump.

The underlying feature — persistent cross-session memory stores for Managed Agents — is the production stabilization of the "Dreaming" capability Anthropic announced at the May developer conference. It addresses essentially the same user need Klatch's Step 10.5 (Layer 5 portability, persona capture) targets, via a different architectural path (platform-managed, cloud-hosted vs. Klatch's local-first import/export approach).

**Source:** https://platform.claude.com/docs/en/managed-agents/memory  
**Klatch impact:** No code change needed (SDK already covers it; Klatch uses direct `messages.stream`, not Managed Agent sessions). Strategic: Anthropic's memory arc is advancing on a faster clock than sweeps had tracked. Step 10.5 should explicitly document why Klatch's approach remains distinct (local-first, provider-agnostic, no Managed Agents dependency). Route to Daedalus + Calliope before next Step 10.5 sprint.  
**Prior mentions:** Dreaming research spike in `docs/research/anthropic-dreaming-import-export-impact-2026-05-12.md` (D1–D5); mail threads `docs/mail/read/argus-to-calliope-managed-agents-dreaming-2026-05-11.md`, `docs/mail/read/argus-to-calliope-dreaming-spike-published-2026-05-12.md`. **Already covered in prior synthesis — frame as update:** memory API now has a stable, versioned header contract.

### 3. Claude Code 2.1.207 (July 11) — Agent View Overhaul + −400 MB Auto-Updater

Agent View rows now show **colored state word + classifier-written headline** instead of raw tool call text. Sessions that edit, merge, comment on, or push to a PR now **link that PR** in the `claude agents` TUI.
