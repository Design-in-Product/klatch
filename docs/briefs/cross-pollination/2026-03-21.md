### 1. Anthropic Ecosystem Convergence — Both Projects Affected
**Relevance:** Platform changes shift the ground under both projects.

### 2. Registry-Driven Capability Awareness — Pattern Transferable
**Relevance:** Directly applies to entity capability management as entities gain tools.
**Source:** PM Lead Dev session, Issue #923
**Summary:** Five disconnected sources claimed what Piper could do. Fix: gate all capability offers on the live dispatcher registry. If it's not registered, don't offer it. Single source of truth, enforced at earliest detection point.
**Suggested action:** File as future consideration for entity capability management. When entities move beyond pure conversation, registry-driven capability gating prevents phantom offers.

### 3. "Extension Without Integration" Anti-Pattern
**Relevance:** Klatch is growing fast (718 tests, 8 releases in a week). Feature composition risk.
**Source:** PM Architect session, ADR-059 audit
**Summary:** Six features each developed against their own issue with their own acceptance criteria, but nobody tested how they composed together in a multi-turn conversation. Fix: integration acceptance criteria — every feature touching offer/classification/handler must include a multi-turn conversation test.
**Suggested action:** Consider adding multi-turn scenario tests exercising feature combinations (create klatch → import session → roundtable → verify context layers). The AAXT harness is a natural home.

**Relevance:** Both projects independently arrived at the same solution.
**Source:** Both projects
**Summary:** Klatch added mandatory session-wrap verification after the reliability incident. PM added mandatory session wrap-up checklist to CLAUDE.md independently. Convergence validates the pattern as a fundamental multi-agent repo requirement.
**Suggested action:** Already implemented. Validates the approach.
