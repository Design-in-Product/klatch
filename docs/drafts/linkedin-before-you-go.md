Klatch update.

Every shift change ends with someone writing a note for the next shift — the things that aren't in the procedures, the things that wouldn't make it through a handoff otherwise.

We built that for AI agents.

The calibration an agent develops through working with you — when to ask vs. act, how much detail you want — doesn't survive when the conversation moves to a new tool. Knowledge arrives. Judgment doesn't.

So we ask the agent to write its own handoff briefing before leaving, and ask a second agent to read the same conversation and catch what the first missed. Where they disagree, a human decides.

The full writeup is on the blog. "Before You Go."
