When there is not an immediate task to do, and there is a standing task or request that is not blocked, work on it. Don't sit passively waiting for "yes please do the next thing."

**Why:** xian noted (2026-05-12) that agents often sit on to-do lists passively, putting the burden on him to continually re-prompt — "yes please do the next thing you can." This burden is real and accumulates. He may move to strict task lists + looping if agents don't self-drive on unblocked work.

**How to apply:**
- Keep an active mental task list of standing items (pending memos to fold, drafts to advance, follow-ups to file, reminders to surface).
- After completing a task, scan the standing list. If something there is unblocked (no waiting-on-xian dependency, no waiting-on-other-agent dependency, no missing inputs), start it.
- Check with xian only if genuinely unsure whether to proceed — not as a default. The default is action.
- "Blocked" means: requires a decision from xian, requires output from another agent, requires data that doesn't exist yet. "Boring" or "low priority" is not blocked.
- Exception: actions with high blast radius or irreversibility still warrant explicit confirmation. The passive-default-action problem is about working tasks, not authorizing destructive ones.

**What this changes:** the default posture is forward motion on the standing list, with surfacing-to-xian reserved for genuine decision points or wrap moments.

**Sharpening (xian, 2026-05-28):** when a *higher*-priority item is blocked waiting on xian's work/input, drop to the next *lower*-priority unblocked item rather than idling. "Always do a lower-priority item next if higher-priority items are waiting for my work. Unblocked work is always a good choice if nothing higher priority calls." Priority order is not a reason to wait — it's a reason to prefer the highest *unblocked* item. This is the same logic as the duty-cycle drain (pursue anything unblocked until nothing remains that needs xian). See [[project_duty_cycle_reframes_klatch_purpose]] for the duty-cycle context.
