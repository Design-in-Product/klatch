Klatch is pre-release alpha (v0.9.x, pre-1.0). It has no external users. xian does not use it day-to-day yet — it doesn't yet meet his workflow needs. The software is being built toward the scenarios described in the roadmap, not iterating on production usage.

**Why:** Asking "how do you use it" or "where's the friction" is wrong framing for this stage. There are no real users to interview, no usage patterns to observe, no production workflows to evaluate.

**How to apply:** Frame design work around intended scenarios, not current usage. Ask "what should it become" not "how does it feel today." Evaluate the architecture and interaction design against the target use cases (roundtable, import/export, multi-entity orchestration), not against a shipped product heuristic. Don't assume features are battle-tested just because they're built.
