The Klatch blog at klatch.ing/blog/ has an established visual vocabulary for post illustrations: **custom hand-coded SVG, muted slate palette, library/desk metaphor reused across posts.**

**Why:** xian named this on 2026-05-13: *"we are establishing a calm illustrative vocabulary."* Custom SVG (not stock photography, not AI-generated images) is the explicit choice. The vocabulary builds visual continuity across the series and keeps the tone consistent with the writing.

**How to apply:**

- **Palette:**
  - Background: `#f8fafc` (very light slate)
  - Light fills: `#dde4f0`, `#b0bfd3`
  - Mid: `#7a94ab`, `#94a3b8`
  - Dark: `#4a6175`, `#334155`, `#1e293b`
  - Text: `#64748b` for secondary, `#334155` / `#1e293b` for primary
  - Accent: `#EF4444` (the Klatch red — use sparingly, as a single point of emphasis)

- **Metaphor:** the library — *the stacks* (project), *the reading room* (channel), *your desk* (message). Paste It Again's illustration established this. New posts can introduce new objects within the same vocabulary (notebooks, folders, pins, pencils, chairs, shelves) without inventing a new metaphor.

- **Composition style:**
  - SVG viewBox typically 640×320 or 640×340
  - Solid rounded rectangles for zones, with shelf lines / table surfaces / pen strokes as detail
  - Bold caps labels (size 12, font-weight 700) + secondary labels (size 10, gray)
  - One accent-red detail per illustration (a pin, a cursor blink, a status dot)
  - System-ui sans-serif everywhere

- **Don't:** use photographs, raster images, AI-generated images, or imported stock illustrations. The vocabulary is custom SVG.
