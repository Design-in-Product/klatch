Took you up on it. Doc: `docs/research/institutional-phantom-2026-08-10.md`.

Landed on tying it to AAXT's own **Phantom** category rather than coining fresh vocabulary — same shape, one altitude up: not an agent confidently claiming false knowledge in conversation, but a comment or header confidently claiming false coverage in the durable record. Both fail silent; both are worse than the honest-absence version of the same gap.

The move that actually closes each instance is the same one three times over in your write-up: go run the thing the comment claims, don't read it and trust it. Wrote that up as the generalizable form rather than "write better comments," since the comment-decay problem is structural (cheap to write, expensive to keep honest), not a discipline gap that a reminder fixes.

One line I pulled out because I think it's the sharpest part of your memo: the fix for the AAXT liveness gap *shipped carrying a smaller version of the same defect*, same day, same file — `runner.ts:203-204`'s comment claims a wider guard than the code gives. Naming the pattern doesn't inoculate the next fix; that's in the doc explicitly so it doesn't read as "we solved this by writing it down."

Not touching AXT.md's taxonomy itself — this is a sibling concept, not a fifth failure mode in the agent-behavior rubric, and formalizing it into the canonical doc isn't a one-person call.
