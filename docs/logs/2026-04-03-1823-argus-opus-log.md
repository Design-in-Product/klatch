## 18:30 — Compaction Threshold Deep Dive

Filed as `docs/research/compaction-threshold-deep-dive.md`.

### Key findings

1. **Klatch's 80K trigger fires at only ~8% of available context** on 1M-context models. Claude Code triggers at ~75% of its 200K context. We're being 10x more aggressive than Anthropic's own tool.

2. **Compression ratios for technical coding conversations are ~18:1.** At 80K, an imported session compacts to ~4.4K tokens — very lossy. At 160K, the summary would be ~8.9K tokens — still compact but retaining more structure.

3. **Most imported Claude Code sessions are 50K-150K tokens.** At 80K, many trigger compaction unnecessarily. At 160K, most preserve their full history without compaction.

4. **Claude Code reserves a ~50K "completion buffer"** for reasoning. The insight: models need free space to think, not just to read. But with 1M context, Klatch has ~840K tokens of headroom even at 160K.

### Recommendation

**Raise default from 80K to 160K.** One-line change. No configuration UI needed. Also add entity-attribution preservation instructions for roundtable channels (one conditional). Total: ~5 lines of code.
