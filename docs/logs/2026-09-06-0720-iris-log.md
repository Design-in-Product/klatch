temporarily reverted to `onChange`-only, ran the new re-click test — failed exactly as
predicted (`expected element not to be checked, but it was`) — then reverted the revert and
re-ran clean. Added two tests: role split (radio-on-chat/checkbox-on-klatch, shared `name`) and
the re-click-clears case. Also had to fix the existing test suite's `listCheckbox` helper in
`composition-path-c-continue-existing-role.test.tsx` — it used `getByRole('checkbox')`, which
no longer matches the chat-form rows; switched it to a role-agnostic `querySelector('input')`
