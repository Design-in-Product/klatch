## 07:50 — Vocabulary pass (Q1–Q5)

Five vocabulary questions resolved, all captured in `docs/ux/object-model.md` under a new Vocabulary section:

- **V1** Channel/chat/klatch/conversation: chats and klatches as primary user-facing categories; conversation as singular generic fallback; channel stays in implementation.
- **V2** Agent/role/entity: agent is the broad user-facing word for any AI participant; role is the subset with persistent identity in a project; entity stays in implementation. The word collision xian named (chat vs. agent) resolves cleanly with "agent."
- **V3** Workflow and meeting both stay internal. The user "sets up a klatch" with direct field-level properties (purpose, agents, cadence, phases, mode). Three audiences three views, extended: agents see chats; user sees klatch; system orchestrates workflow underneath.
- **V4** Composition verbs: **invite** (add agent to existing klatch) + **convene** (create new klatch). Slack-flavored convention; the "invitation implies optionality" tension acknowledged as familiar.
- **V5** Promotion: naming an agent IS the promotion. No separate verb in UI. "Promote" stays in internal vocabulary. The naming flow IS the promotion flow.
