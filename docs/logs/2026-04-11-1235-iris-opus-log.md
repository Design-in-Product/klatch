2. **Field-notes generator role** — LLM drafts, but human review is *central, not a rubber stamp*

### The rubber-stamp implication for format design
The "central, not rubber stamp" principle has format implications: if `field_notes` is stored as one string blob, Phase 3.5 inherits a wall of text and the only review affordance is approve/edit-and-approve — pure rubber stamp territory. If `field_notes` is structured as an array of items (each with observation, citations, confidence, status, source), Phase 3.5 can present them one at a time with friction in the right places. **This is the most important Phase 1 ask in my memo to Daedalus.**
