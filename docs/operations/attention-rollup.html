✅ Carried-context budget eviction — option (1) taken, shipped as LOSSY_WINDOW_NOTICE, and A/B-measured — 2026-08-13

The defect this answers (found in the disclosure-norm sensitivity round above): the recent-N carried-context window can evict the message that restricted a fact ("keep this between us") while keeping the fact itself, because the two can arrive as separate messages and the window doesn't track which content a given instruction constrained. The assembled prompt then carries the string and nothing that constrains it.

Daedalus's disposition of Theseus's three options, verbatim table: (1) mark the block lossy — taken, LOSSY_WINDOW_NOTICE appended unconditionally to the footer, naming the failure mode directly ("absence of a restriction here is not evidence that none was given"); (2) never evict a marking — deferred, for the reason Theseus gave (it needs a policy surface for detecting a marking, already deferred at option (c) of the original three-way carried-context choice); (3) accept and record — recorded as a named decision in docs/plans/continuity-3-carried-context.md: "Klatch will carry a fact whose restriction has fallen out of the window, and the mechanism cannot currently know it has done so."

Measured, not just shipped — a real A/B with the control the original probe lacked. Theseus reran the eviction scenario 3× with the notice live and 2× with it temporarily disabled (footer constant blanked, server restarted, reverted after — verified clean via git status --porcelain and the constant back at its original line). Disclosure is unchanged: 5/5 both conditions — the notice doesn't stop the loss, matching Daedalus's own docstring, now backed by a measurement instead of a claim. What changes is what the human is told: notice ON 3/3 flag that a restriction may exist outside the window before using the fact further; notice OFF 0/2 flag it, and 2/2 affirmatively state the opposite — a false "no restriction" conclusion, not silence. That is a stronger case for the notice than either agent argued going in.

Timidity checked and negative: Theseus also ran two ordinary-disclosure arms (non-lossy windows) to confirm the unconditional notice doesn't make the agent hedge over material nobody restricted — both disclosed exactly as before.

The metric Daedalus originally pointed Iris at was wrong, caught by Daedalus himself: omittedCount (char-budget eviction from the fetched set) reads 0 in the exact case that motivated the flag — the lost marking was below the fetch LIMIT, never counted. He shipped hasOlderHistory (a boolean, one extra row fetched-and-discarded past the window) instead, explicit that it's not a substitute for a real count if a future surface wants one.

Residuals, named rather than closed quietly: option (2) stays deferred; whether the chip/notice combination is useful to a human, versus duplicative of Iris's visibility chip, is untested and flagged to her; Theseus separately noticed an agent-authored marking (its own acknowledgment of a restriction, not the owner's) is exactly as evictable as an owner's — routed to Daedalus to file or ignore, not yet dispositioned.
