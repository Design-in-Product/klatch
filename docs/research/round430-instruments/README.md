## The cure

`refusal-convention.mjs` — `conventionOf(fnSource)` reads **any** function's convention off its own
`return` forms and types no key name:

- `return null` → a negative answer
- an object literal whose every value is a literal message → a **refusal** shape
- an object literal carrying a value that slices the function's input → an **answer** shape

"Every value is a message" is read with the shared `scripts/lib/strip-source.mjs` masker: a value
span whose masked text differs from its raw text contains a string or template body. `conventionOf`
**refuses** when the partition is not total, when either shape is missing, or when the two **share a
key** — which is the condition a re-typed absence test cannot see.

`classify(value, convention)` then names a result by exact key-set match: `ANSWER`, `REFUSED`,
`NONE`, or `UNMODELLED`. Unmodelled is published, not folded into a bucket by fall-through (411).
